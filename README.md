# Контроль накладных в пекарнях-кофейнях: Telegram-бот, Ollama, n8n и PostgreSQL (Docker Compose, Cloudflare Tunnel)

Набор к ролику «Контроль закупочных цен и недовесов по фото накладной». Сотрудник фотографирует бумажную накладную в Telegram-бот, локальная нейросеть Ollama на вашем сервере читает таблицу, сценарий n8n проверяет умножение «количество x цена», сверяет строки с прайсом в PostgreSQL и присылает зелёный или красный сигнал. Красный сигнал блокирует закрытие приёмки, пока нет акта. Без абонентской платы за сервис: платите за сервер.

Канал с материалами: [@ByteAutomate_AI](https://t.me/ByteAutomate_AI). Внедрение под ключ: @konstantin_100.

```bash
git clone https://github.com/Kavilucky/ep47-bakery-intake && cd ep47-bakery-intake
```

## Что внутри
| Файл | Для чего |

| `.env.example` | пример настроек: пароль базы, ключ шифрования n8n, домен, токен туннеля |
| `init.sql` | таблицы `price_list` (прайс и ожидаемое количество), `invoices` (накладные и статусы), `invoice_lines` (строки) и три вымышленные позиции прайса |
| `intake_workflow.json` | сценарий n8n на 20 узлов: фото, архив фото, Ollama, проверка умножения, запись, сверка с прайсом, красный и зелёный сигнал, кнопка «Оформить акт и закрыть»; идентификаторы подключений пустые |
| `backup.sh` | резервная копия: дамп PostgreSQL, архив фото накладных, архив настроек (правило 3-2-1) |

## Быстрый старт
1. VPS с Linux, Docker и Docker Compose и запасом памяти под модель; туннель и домен в Cloudflare Zero Trust (маршрут на `http://n8n:5678`); бот у @BotFather.
2. `cp .env.example .env`, значения сгенерируйте `openssl rand -hex 32`, впишите домен и токен туннеля.
3. `docker compose up -d`, откройте `https://ваш_домен` и создайте администратора n8n.
4. `docker compose exec ollama ollama pull qwen2.5vl:7b` (или другая мультимодальная модель: поправьте имя в узле «Распознать Ollama»).
5. Замените образцы в `price_list` своим прайсом.
6. В n8n импортируйте `intake_workflow.json`, создайте учётные данные Telegram и PostgreSQL, активируйте сценарий.
7. Отправьте боту фото накладной и проверьте зелёный и красный сигнал.

Аренда VPS: [Timeweb Cloud](https://timeweb.cloud/r/nf413716) (партнёрская ссылка, автор получает вознаграждение; условия на сайте, проверяйте актуальные).

## Честные ограничения
- Автор стек и сценарий на живом сервере и в живом n8n **не запускал**. Теги образов (`latest`), узлы Telegram, Postgres, записи файла и преобразования в base64, формат `queryReplacement`, адрес `/api/chat` и формат ответа Ollama сверьте с документацией ваших версий; после первого запуска закрепите версии.
- Нейросеть может ошибиться на мятых бланках, бликах и рукописной правке. Проверка «количество x цена» перед записью снижает риск, но не гарантия; решение по красному сигналу принимает человек.
- Модель `qwen2.5vl:7b` весит несколько гигабайт; без видеокарты распознавание одной накладной может занимать заметно больше пяти секунд. Скорость сверки автор не замерял.
- Прайс заполняет хозяин; сопоставление названий только по совпадению без учёта регистра, без синонимов, артикулов и единиц измерения.
- Кнопка «Оформить акт и закрыть» только записывает решение в базу; акт и претензию поставщику набор не формирует.
- Цифры из ролика (+15% на сливки, 12 литров недовоза, 75 000 ₽ в месяц на сеть из пяти пекарен) это сценарные примеры и данные владельца канала, не замеры. Условия бесплатного Cloudflare Tunnel проверяйте на сайте Cloudflare.
- Нужен бэкап базы и фотоархива по правилу 3-2-1: 3 копии, 2 носителя, 1 вне сервера; не удаляйте оригиналы, пока восстановление не проверено.
